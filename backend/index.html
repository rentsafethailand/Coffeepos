📚 คู่มือการใช้งาน Variants และ Modifiers

🎯 Variants และ Modifiers คืออะไร?

  • Variants = ตัวเลือกพื้นฐานของสินค้าที่ลูกค้าต้องเลือก เช่น ขนาด, อุณหภูมิ, ความหวาน
  • Modifiers = ท็อปปิ้งหรือส่วนเสริมที่ลูกค้าสามารถเลือกเพิ่มได้ เช่น วิปครีม, ช็อตกาแฟเพิ่ม

Variants (ตัวเลือกสินค้า)

วิธีการตั้งค่า Variants:

  1. กดปุ่ม "จัดการ Variants/Modifiers"
  2. ในส่วน Variants กดปุ่ม "เพิ่ม Variant"
  3. เลือก Product ที่ต้องการ
  4. เลือก Variant Type (ประเภทตัวเลือก)
  5. กรอก Variant Value (ค่าตัวเลือก)
  6. กรอก Display Name (ชื่อแสดง)
  7. กรอก Price Adjust (ปรับราคา +/-)

✨ ตัวอย่าง Variants สำหรับเครื่องดื่ม:

Variant Type: SIZE (ขนาด)

• SMALL (เล็ก) - Price Adjust: 0

• MEDIUM (กลาง) - Price Adjust: 0

• LARGE (ใหญ่) - Price Adjust: +10

Variant Type: TEMPERATURE (อุณหภูมิ)

• HOT (ร้อน) - Price Adjust: 0

• COLD (เย็น) - Price Adjust: 0

Variant Type: SWEETNESS (ความหวาน)

• 0% - Price Adjust: 0

• 25% - Price Adjust: 0

• 50% - Price Adjust: 0

• 75% - Price Adjust: 0

• 100% - Price Adjust: 0

Modifiers (ท็อปปิ้ง/ส่วนเสริม)

วิธีการตั้งค่า Modifiers:

  1. กดปุ่ม "จัดการ Variants/Modifiers"
  2. ในส่วน Modifiers กดปุ่ม "เพิ่ม Modifier"
  3. เลือก Product (หรือเว้นว่างถ้าต้องการใช้กับทุกสินค้า)
  4. กรอกชื่อ Modifier
  5. กรอกราคาเพิ่ม
  6. เลือกประเภท (TOPPING, EXTRA, etc.)

✨ ตัวอย่าง Modifiers:

💡 เคล็ดลับการใช้งาน:

  • ใช้ isDefault: true เพื่อกำหนดตัวเลือกเริ่มต้น (เช่น MEDIUM, HOT, 50%)
  • ใช้ sortOrder เพื่อจัดลำดับการแสดงผล (เลขน้อยแสดงก่อน)
  • Modifiers ที่ productId = null จะใช้ได้กับทุกสินค้า
  • Price Adjust สามารถเป็นค่าลบได้ (เช่น ลดราคา -5)
